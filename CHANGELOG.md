# Changelog

## [0.2.0] - 2026-11-11

- Hide fenced code block rows while preserving Pi's native syntax highlighting.
- Restore the original Pi Markdown renderer during extension shutdown and reload.

## [0.1.0] - 2026-11-11

- Compact single-line path, command, and log-value code blocks in assistant Markdown.
- Preserve separate multi-line and language-labeled code blocks with Pi's native renderer.
- Package the extension as a standard Pi package.
